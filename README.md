# PrintHub Express 🖨️⚡

Website profil dan kalkulator estimasi harga cetak digital & outdoor printing untuk **PrintHub Express**. Dibuat untuk pemenuhan tugas mata kuliah Kewirausahaan 2.

---

## 🌟 Fitur Utama

1. **Desain Modern Bertema CMYK**:
   - Identitas visual industri percetakan dengan perpaduan palet warna CMYK modern (Cyan, Magenta, Yellow, Key/Black).
   - Tipografi modern menggunakan Google Fonts (Poppins & Inter).

2. **Katalog Produk & Layanan**:
   - **MMT / Spanduk & Banner Luar Ruang**: Hitungan per meter persegi ($m^2$) dengan bahan Flexi tahan cuaca.
   - **Digital Lembaran A3+**: Brosur, menu, kalender, poster, dan stiker label kemasan.
   - **Print & Fotocopy Dokumen A4**: Kebutuhan tugas mahasiswa dan perkantoran.

3. **Kalkulator Estimasi Biaya Interaktif**:
   - Menghitung estimasi biaya cetak secara otomatis langsung di browser.
   - Fitur perhitungan dimensi panjang & lebar khusus untuk banner/MMT.
   - Perhitungan jumlah lembar/pcs instan.

4. **Integrasi Direct Order via WhatsApp**:
   - Mengonversi rincian pesanan dari kalkulator secara otomatis menjadi format pesan WhatsApp yang rapi dan terstruktur.

5. **Responsif**:
   - Tampilan optimal baik diakses melalui smartphone, tablet, maupun desktop.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Semantik struktur web modern
- **CSS3**: Vanilla CSS dengan CSS Variables, CSS Grid, Flexbox, dan efek transisi/animasi halus
- **JavaScript**: Vanilla JS untuk logika kalkulator harga dinamis dan format URL WhatsApp
- **Google Fonts**: Poppins & Inter
- **Font Awesome 6**: Ikonografi modern
